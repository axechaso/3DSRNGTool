# G6 时间线与 TinyMT 索引搜索

在主窗口的「工具 → G6 TinyMT 索引搜索 (TinyFinder)」打开。使用四段 TinyMT 状态、32 位初始种子，或模拟器的 UTC 时钟初始化。四段状态显示顺序为 **3、2、1、0**，与原时间线工具一致。

## 已整合的功能

参考 [Bambo-Rambo/TinyFinder](https://github.com/Bambo-Rambo/TinyFinder)，在现有 TinyMT 与遭遇计算上实现索引搜索：

| 方式 | 预测内容 |
| --- | --- |
| 普通野生、朋友原野 | 同步、遭遇成功、槽位、携带物与笛子等级 |
| 蜂蜜群战、走路群战 | 同步、槽位、隐藏特性位置、五只的携带物与笛子等级 |
| 蜂蜜单体、钓鱼、碎岩 | 背包与眨眼推进、随机延迟、遭遇检查、槽位与携带物 |
| 宝可追踪 | 首次遭遇，以及连锁中的草丛分布、音乐和闪光草丛 |
| XY 洞穴落影 | 槽位、同步与携带物 |
| 训练家 ID | TID、SID、TSV、TRV，支持 TID / TSV 筛选 |
| ORAS DexNav 走路、主动搜索 | 同步、出现检查、潜力、隐藏特性、遗传招式有无、强制闪光与位置 |

搜索在后台执行，可停止，支持起止索引、结果上限、同步、槽位、隐藏特性、潜力、强闪/闪草筛选。与当前方式无关的筛选项会禁用。

选中结果可复制状态或回填原工具。ID 结果同步回填原 ID 搜索输入；群战结果保存五只的完整 TinyMT 数据供原群战主 MT 搜索使用；当前主窗口处于 DexNav 时，也会填入隐藏特性、潜力和强制闪光设置。

## 参数与计数约定

- 索引 **0** 是输入状态、下一次 TinyMT 调用之前；范围包含两端。初始偏移只用于种子/RTC 初始化，不作用于直接输入的四段状态。
- RTC 按输入的 **UTC** 时钟计算从 2000-01-01 起的毫秒数，取低 32 位，不受电脑时区或夏令时影响。模拟器时钟若按本地时间显示，需要先换算 UTC。RTC 初始化的游戏启动偏移通常为 1，ID 为 2；直接种子默认 0。
- 主动 DexNav 的输入状态位于首次长眨眼周期计算之前。原 TinyFinder 对此方式在搜索前使用 `Min - 1`；本工具统一按输入状态起算，比较两个界面时需考虑这个一位偏移。
- NPC 调用数、背包调用数、长眨眼帧、交互 MT 帧及蜂蜜延迟需要按场景设置。背包通常为 ORAS 15、XY 27，洞穴等场景可能是 3 或其他值；默认值不能替代场景校准。
- 同步、遭遇槽位等属于 TinyMT；性格、个体值和普通闪光仍由主 MT 计算。索引并不等于主 MT 帧。回填新状态后，原时间线需要重新校准事件帧，或检查手动事件设置后重新生成。
- 此次未迁移 TinyFinder 的完整地点/NPC 数据库、RTC 日期范围扫描、遗传招式名称数据库。DexNav 显示遗传招式有无；雷达显示草丛图。普通物种仍由原工具的地点遭遇表选择。

## 时间线修复

- 每次生成从原始校准快照重新开始，重复搜索不改写校准状态。
- 空事件队列可正常经过时间，缺少校准、负延迟和无效碎岩延迟会报错，避免异常或无限循环。
- 根据延迟长度补足参考范围，避免频繁 NPC 调用时长延迟结果丢失。
- 朋友原野使用 50/50 或 34/33/33 概率，不再误用第七世代钓鱼槽位表。
- 主搜索按实际帧差推进主 MT，处理奇数起点、区间空隙与终点裁剪。
- 主搜索始终计入遭遇延迟，不再依赖预览的「考虑延迟」复选框；按宝可梦模板读取叫声帧。
- 保留翻译、重新打开窗口时的校准事件与参数，修复主窗口设置被默认值覆盖、隐藏窗口漏读遭遇率的问题。
- 支持短眨眼阶段的 NTR 校准类型；修复无连接停止校准、非群战结果读取 HA 导致的空引用。
- 遭遇开始后停止 fidget，避免主窗口的野生计算与时间线预览使用不同事件队列。

## 验证与来源

`TinyFinder-vectors.json` 是从原仓库提交 [`2133fe761958094ed69709aead9d7b162673e737`](https://github.com/Bambo-Rambo/TinyFinder/tree/2133fe761958094ed69709aead9d7b162673e737) 独立构建导出的 **456 组**输入/输出数据，覆盖 12 种方式、两组游戏、队伍数、NPC、背包、连锁、搜索等级和眨眼跨周期情形。检查比较同步、成功检查、槽位、携带物、笛子、HA、潜力、遗传招式、强闪、雷达图、延迟和 ID。项目不打包原 TinyFinder 程序。

其他回归检查覆盖重复生成、空队列、短眨眼、朋友原野概率、6000 帧延迟、区间边界、筛选与取消、RTC 时区独立性、隐藏窗口设置、主窗口 MT 对齐与新窗口搜索/回填。

这是代码和对照样例验证，尚未用实机或模拟器逐场景验证 NTR 断点及交互时机。

```powershell
msbuild 3DSRNGTool.sln /p:Configuration=Release
.\Tests\Gen6\bin\Release\Gen6.Tests.exe
.\Tests\EncounterTables\bin\Release\EncounterTables.Tests.exe
```

缺少 4.5.2 引用程序集时，请使用 [遭遇表检查说明](../EncounterTables/README.md) 中的 NuGet 引用程序集构建方式。
